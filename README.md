# Advanced Electromagnetic Fields and Waves

Interactive course resources for PHY709 at COMSATS University Islamabad.

## Electrostatic Potential Explorer

The interactive page supports graduate-level study of:

- electrostatic potential and electric fields;
- Poisson and Laplace equations;
- boundary conditions and uniqueness;
- analytical benchmark configurations;
- finite-difference relaxation;
- numerical validation and self-assessment.

Open `index.html` through the published course site.
